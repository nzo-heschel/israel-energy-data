NZO Energy Data API ממשק שאילתות וניהול נתוני נגה
API Server Active
⚡ REST Data Service

ברוכים הבאים לשרת הנתונים של NZO

ממשק ה-API מאפשר שליפה מהירה של נתוני משק החשמל מנגה (מחיר שולי SMP, תמהיל ייצור, ביקוש ופליטות CO₂) במגוון פורמטים: JSON, CSV, TSV, HTML ו-MsgPack.

דוגמאות לשאילתות נפוצות (Sample Queries)

GET /get JSON (Default)

נתוני מחיר שולי (SMP) שעתיים

שליפת נתוני החודש האחרון של המחיר השולי במערכת (SMP) באגרגציה שעתית בפורמט JSON.

/get?source=noga2&type=smp&time=hour
GET /get CSV / TSV

נתוני עלות יומיים לשנת 2024

ייצוא נתוני שנת 2024 באגרגציה יומית לקובץ CSV (ניתן להשתמש ב-format=tsv להפרדת טאבים).

/get?source=noga2&type=cost&start_date=01-01-2024&end_date=31-12-2024&time=day&format=csv
GET /get HTML Table

תחזית ביקוש מערכתית (Forecast-1)

נתוני דצמבר 2022 ברזולוציה מלאה (חצי-שעתית) של תחזית הביקוש יום מראש כטבלת HTML.

/get?source=noga2&type=forecast1&start_date=01-12-2022&end_date=31-12-2022&time=all&tag=SystemDemand&format=html

פרמטרים נתמכים בנקודת הקצה /get

פרמטר ערכים אפשריים תיאור
source noga2, noga, all מקור הנתונים במערכת
type smp, energy, co2emission, system_demand, cost, forecast1, forecast2 סוג סדרת הנתונים המבוקשת
time all, hour, day, month רמת האגרגציה על ציר הזמן
format json, csv, tsv, html, bin פורמט הפלט המוחזר
